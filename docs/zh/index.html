产品理念

不是又一个「打分 + 写点评」。

星级和海量点评告诉你陌生人怎么想。对味告诉你——你自己会怎么想。每一次排名都在打磨你的口味模型；关注好友后，和你越对味的人，话语权越大；不断探索，你的美食足迹就沉淀成一种身份。

🎯

个人口味

一枚学习得到的口味向量，把你和每一家餐厅放进同一个空间，推荐真正属于你——而且每个匹配都有理由。

🤝

社交发现

「对味度」决定谁的意见更重要。96% 的口味搭子能左右推荐，口味相去甚远的人则不会。

🌏

探索收集

排行榜、成就和美食护照，把你吃过的地方变成值得晒的进度。

为中国的生活方式而生

打通你已经在用的超级 App。

对味不做又一个孤岛。它接进你日常已经在用的生态——一处口味模型，处处可用。以下为面向中国市场的产品打通设想，尚未接入真实接口。

概念设想
💬
微信登录 · 社交关系 · 分享 · 小程序
  • 一键微信登录，导入通讯录好友，直接找到你的「对味搭子」。
  • 把「我的上海 Top 10」分享到朋友圈或好友群，附带精美榜单卡片。
  • 「对味小程序」即点即用，无需下载，用完即走。
  • 拼饭结果一键发到群里，好友投票选定今晚这家。
概念设想
💰
支付宝预订 · 到店买单 · 信用 · 小程序
  • 芝麻信用免押预约，到店扫码买单，「发现—预订—买单」一条龙。
  • 支付宝小程序入口，触达不装 App 的用户。
  • 消费记录（脱敏授权后）回流，自动补全你的口味模型与美食护照。
  • 结合口碑/饿了么优惠，在对味的推荐里透明呈现。
概念设想
⭐
大众点评历史导入 · 差异化定位
  • 导入你在点评的到店记录与收藏，一键转化为你的口味模型。
  • 核心差异：点评看陌生人的平均分，对味只看你、以及和你对味的人。
  • 把点评的「必吃榜」当作探索线索，用「对味度」重新为你排序。
概念设想
📕
小红书一键成图 · 种草 · 内容分发
  • 把你的排行榜、口味档案、美食护照，一键生成精美笔记图。
  • 自动带话题：#上海美食 #探店 #对味，种草不费力。
  • 「对味卡片」自带你与好友的口味相似度，天然适合社交传播。
💬 微信小程序优先

面向中国市场，除原生 iOS App 外，规划一个微信小程序版本作为增长入口：零下载门槛、借助社交裂变分享榜单与拼饭邀请，把口味模型和成就体系无缝带进微信生态。

为社交传播而生的「对味卡片」

每一张榜单、每一次口味匹配，都能一键导出成适合小红书 / 朋友圈 / 微信群的竖版卡片。分享内容自带你的品味与身份，天然带来拉新——这正是把发现变成增长的关键。

产品闭环

每一顿饭，都让下一次推荐更懂你。

排名产生偏好数据 → 推荐更准 → 使用更多 → 数据更丰富。好友提供可信信号，成就带你走向没去过的地方。

核心功能

是一个完整产品，而不是一屏演示。

五大页面、十余个深度流程——全部可交互，由本地推荐 / 排名 / 成就三大引擎驱动。

✨

个性化对味度

醒目、可解释的匹配分——「契合你对川菜的偏好 · Jason（对味 96%）将它列为川菜第一」——比星级更响亮。

⚖️

两两对比排名

标记「去过」后回答几个「更喜欢哪一个？」，看它动画滑入你的城市榜单。

👯

口味相似度

用偏好向量的余弦相似度，找到你的「口味搭子」——也俏皮地告诉你们在哪儿不合。

🍽

拼饭推荐

选好一桌人，给出兼顾满意度、又惩罚分歧的那一家。

🛂

美食护照

把你的排名历史变成按国家分组的城市印章，精确到街区的探索完成度。

🏅

成就体系

徽章（专精）· 印章（地点）· 奖章（成就），五档稀有度——靠探索赢得，而非刷出来。

技术内核

真引擎，而非写死的页面。

所有业务逻辑都在纯粹、可测试的引擎里——绝不写进视图。把本地 mock 服务换成后端，界面无需改动。

推荐引擎 RecommendationEngine 得分 = 0.45·口味 + 0.25·好友 + 0.20·场景 + 0.05·热度 + 0.05·新鲜度
  • 口味 — 你的偏好与餐厅属性的余弦相似度。
  • 好友 — 支持者按他们与你的对味度加权。
  • 场景 — 从一次轻松的提问中读取：场合、预算、距离、氛围。
  • 新鲜度 — 把你推向没探索过的菜系与隐藏小店。
排名引擎二分插入（约 log₂n 次提问）叠加 Bradley-Terry 隐分，榜单平滑可比。
成就引擎完全数据驱动：40+ 成就均为纯声明，进度对着实时统计快照计算。
在线口味学习每次排名都让偏好向量漂移——发现页会随使用明显变化。
