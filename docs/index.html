What to expect

Real listings, with clear limits.

Apple Maps supplies search results, not an exhaustive regional directory. Search by name or cuisine, move to a smaller map area, or tap a restaurant’s native map pin to find more places. Coverage and accuracy depend on Apple Maps.

No invented restaurant data

Unavailable prices stay unavailable. Live listings do not show fabricated match percentages, Michelin ratings, menus, photos, or friend activity.

A local-first release

There are no accounts, cloud sync, or live social features yet. These require further development; the old seeded social network is not part of the normal app.

Run it yourself

Open in Xcode. Start exploring.

The source is available on GitHub. This is an iOS app you build locally, not an App Store download.

  1. Open Bite.xcodeproj in Xcode 16 or newer.
  2. Choose the Bite scheme and an iOS 18+ device or simulator.
  3. Run, finish the welcome screen, and tap Near me or search an area.

On Simulator, set Features → Location before using Near me. On a physical device, select your own signing team. Search and map tiles need an internet connection.

Built to be checked

The repository includes 13 core regression tests, 3 simulator UI tests, and CI for core tests and the iOS simulator build.

A few useful details

Does it show every restaurant?

No. Apple Maps returns a selection of search results. Bite displays all returned listings within the requested area, and you can also open native restaurant pins on the map.

Does it work without location access?

Yes. Search a city, neighborhood, or address manually. Near me requests a one-time location fix only when you choose it.

What works offline?

Your saved restaurant details and rankings remain available. New searches, map tiles, and external websites require a connection.

What happened to the demo data?

The old prototype data file is preserved separately and is not imported into your live profile. Fictional friends and seeded rankings do not appear in the normal app.

Is there a Chinese version of the app?

This website has English and Chinese pages. The current app interface and these screenshots are in English; full app localization is not implemented.
